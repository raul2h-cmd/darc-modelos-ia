DARC — PREPARACIÓN DE LICENCIAS PARA GITHUB

1. Extrae TODO el contenido de este ZIP en una carpeta.
2. Haz doble clic en PREPARAR_LICENCIAS.bat (necesitas internet en tu PC). Descarga automáticamente la copia completa y actual de los términos y la política desde la documentación oficial de Google en GitHub.
3. Abre https://github.com/raul2h-cmd/darc-modelos-ia
4. Pulsa Add file > Upload files, arrastra README.md, NOTICE.txt, GEMMA_TERMS_OF_USE.md, GEMMA_PROHIBITED_USE_POLICY.md, DARC_MODEL_USE_CONDITIONS.md y SHA256SUMS.txt y confirma el commit (README.md reemplaza el original).
5. En Releases > gemma3-1b-v1 > Edit, adjunta también NOTICE.txt, GEMMA_TERMS_OF_USE.md y GEMMA_PROHIBITED_USE_POLICY.md, para que acompañen a la descarga del modelo.
6. El APK de DARC debe informar las restricciones de uso y solicitar aceptación expresa antes de descargar o instalar Gemma; esta acción requerirá una actualización posterior de la aplicación.

No subas los archivos .bat/.ps1 a GitHub: son herramientas locales para descargar las copias legales oficiales.

Aclaración: el modelo de 584 MB YA está subido a GitHub Releases. No lo vuelvas a subir.
