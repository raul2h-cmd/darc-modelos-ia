No se necesita una cuenta de GitHub ni de Hugging Face para usar este enlace de descarga de GitHub Releases.

## Cómo instalar

1. En DARC abre **Asistente jurídico → Modelo local**.
2. Si está disponible, pulsa **Descargar e instalar IA**. Si no, usa el enlace anterior y guarda el archivo.
3. Desde DARC selecciona **Importar archivo .litertlm** y elige el archivo descargado.
4. Lee y acepta los términos de Gemma antes de instalar o usar el modelo.

Después de instalarlo, el asistente puede funcionar sin conexión en teléfonos compatibles.

## Términos y restricciones de uso

Gemma está sujeto a los [Gemma Terms of Use](GEMMA_TERMS_OF_USE.md) y a la [Gemma Prohibited Use Policy](GEMMA_PROHIBITED_USE_POLICY.md). Consulta asimismo [NOTICE.txt](NOTICE.txt) y [las condiciones para DARC](DARC_MODEL_USE_CONDITIONS.md).

Los términos restringen, entre otras actividades, el ejercicio profesional ilegal o no autorizado y las decisiones automatizadas que afecten derechos de personas en el ámbito legal. DARC es una herramienta auxiliar; no toma decisiones judiciales. La instalación del modelo debe exigir aceptación expresa de estas condiciones.
